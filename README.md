# Fast API

FastAPI is a modern Python framework used to build APIs (backend services) quickly and efficiently.

Think of it like this:

Your frontend/app → sends a request → FastAPI → processes it → sends back data


Why is it called "Fast"?

FastAPI is designed for high performance. It uses Python's async/await capabilities and the high-performance Starlette framework underneath.

It is also fast to develop with, because it automatically provides things like:

✅ Request validation
✅ JSON handling
✅ API documentation
✅ Type checking
✅ Async support
✅ Automatic OpenAPI/Swagger documentation
